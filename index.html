사용법 · 주의
  • 한 단계 = 목표 온도까지 승/하온 → 그 온도에서 유지. 유지가 없으면 0
  • 장입 시간 = |목표 − 출발| ÷ 속도 → 반올림 단위로 반올림
  • 반올림 때문에 실제 속도가 설정과 5% 이상 다르면 경고 표시
  • 한 단계는 세그먼트 2개(승/하온 + 유지)로 펼쳐짐. 0분 세그먼트는 생략 가능
  • A: 'SV n, 시간 n' = 현재 온도에서 SV n까지 시간 n 동안 이동 (SSV 시작 온도 설정 방식)
  • B: 'SV n, 시간 n' = SV n에서 SV n+1까지 시간 n 동안 이동 (첫 SV가 시작 온도)
  • 방식은 컨트롤러 매뉴얼 또는 기존 장입 기록과 대조해 확인
  • 냉각 구간: 설정 속도는 상한일 뿐, 저온 영역은 자연 냉각이 더 느려 실제 종료가 늦어질 수 있음
  • 세그먼트당 최대 입력 시간 제한, 종료 처리(END/HOLD)는 검사하지 않음
